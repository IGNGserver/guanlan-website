# 官网定位与范围（SITE）

> 本文为后续开发者（含 AI 会话）提供站点上下文。范围或技术决策变化时同步更新本文件。

## 是什么

观澜 / Guanlan 的产品官网：介绍产品、展示控制台与客户端界面、提供下载入口与部署文档链接，
并作为搜索引擎与 AI 工具的可引用入口。站点与产品仓库分离：

| 事项 | 归属 |
| --- | --- |
| 产品功能、版本、发布资产、产品文档 | 产品仓库 `IGNGserver/guanlan-monitor` |
| 页面、样式、静态资源、SEO、站点文案 | 本仓库 |

## 产品事实（引用时必须与产品仓库对齐）

- 私有部署的电脑与服务器运行状态监控工具；
- 客户端矩阵：Web 控制台、Windows 桌面端、GNOME Linux 桌面端、Android 客户端；
- 监控内容：CPU、内存、磁盘、网络、显卡、风扇等实时数据与历史趋势；
- 下载与安装：只通过产品仓库的 GitHub Releases（稳定版以 Releases 为准，`main` 不是安装源）；
- 中枢部署：Docker Compose（镜像来自 GHCR），客户端与 agent 使用同一公开入口连接。

- 只陈述产品仓库当前支持的事实，不编造路线图；版本与平台矩阵以产品仓库 `README.md` / Releases 为准；
